# switch-ext-clock

Timers and stopwatches: start, pause, lap and chime, kept by wall-clock time so they run while nothing's open. Its widget lists them in Home.

A [Switch](https://switch.ax) extension, built on
[switch-ext-kit](https://github.com/zachsents/switch-ext-kit).

## Install

Ask Switch's agent to install `github:zachsents/switch-ext-clock`, or add it in the desktop's
Extensions view (⌘K, Extensions). Switch runs it on the first machine with what it needs.

## Develop

```sh
bun install
bun run check
bun start   # serves MCP on stdio
```
